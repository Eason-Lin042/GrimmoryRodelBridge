Sync supports one EPUB per book, the same content version, and normal updates from Grimmory Web and this bridge. Unknown progress sources or content changes pause sync.

  1. Add a Reader source Set the access token to the device token. Do not append /reader3 to the address.
  2. Add an OPDS source Use your Grimmory username and the same device token as the password.
  3. Download the EPUB through OPDS, then open it in Rodel.Reader's main library. Keep the Reader source configured for chapter sync.

Existing progress with an unknown source is not migrated automatically. After a content update, the old copy stops syncing and a new import may create a second local entry. Existing books are not deleted automatically.
